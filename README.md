# Hasad حصاد — clickable platform mockup

Static website: plain HTML, CSS and JavaScript. No build step, no server code, no database.

## Host it
Upload the whole `hasad-mockup` folder (keep the `assets` folder next to the pages) to any static host, for example:
- **Netlify Drop:** drag the folder onto app.netlify.com/drop.
- **GitHub Pages:** push the folder to a repository and enable Pages.
- **Your own server or a subdomain** (e.g. `mockup.249startups.com`): copy the files into the web root.

`index.html` (the landing page) is the entry point. A "Screens" button in the bottom-left corner of every page lists all 11 screens.

## Screens
| File | Screen |
|---|---|
| index.html | Landing page |
| dashboard.html | Member dashboard |
| tenders.html | Tenders |
| opportunities.html | Funding and support opportunities |

| mobile-ar.html | Mobile opportunities, Arabic |
| pricing.html | Plans and pricing (monthly / annual switch) |
| upgrade.html | Mobile upgrade prompt |
| farm-planner.html | Farm Planner (fully interactive) |

## Notes

- This is a design mockup: forms do not submit and figures are illustrative or from the cited sources.
- Farm Planner figures come from a confidential 249Startups crop manual (sample). Consider password-protecting the site before sharing the link outside 249Startups.
